# SPEC-010: アカウント管理

## 概要
管理者が作業員・管理者のアカウントを作成・編集・削除する。
パスワード管理は管理者が一括で行う（作業員にはパスワード変更機能を提供しない）。

## 対応画面
- A-06: アカウント管理画面

## 対応ユースケース・ルール
- 境界コンテキスト「認証・アカウント」ルール#7, #9

---

## 受入基準

### アカウント一覧
- [ ] 全アカウントが一覧表示される（名前、ユーザーID、ロール、言語）
- [ ] 各アカウントに [編集] / [削除] ボタンがある
- [ ] 管理者アカウントも削除可能

### 新規アカウント作成
- [ ] [＋ 新規アカウント作成] で作成モーダルが開く
- [ ] 入力項目:
  - 名前（必須）
  - ユーザーID（必須・一意）
  - パスワード（必須）
  - パスワード確認（必須・パスワードと一致）
  - ロール: worker / admin（必須・ラジオボタン）
  - 言語: 日本語 / English / シンハラ語（必須・ラジオボタン）
- [ ] [作成] でアカウントが作成されモーダルが閉じる

### アカウント編集
- [ ] [編集] で編集モーダルが開く（既存データがプリセット）
- [ ] 編集可能項目: 名前、ロール、言語
- [ ] ユーザーIDは変更不可（読み取り専用で表示）
- [ ] [🔑 パスワードをリセット] ボタンで新パスワード入力欄が展開する
- [ ] パスワードリセットは任意（押さなければパスワードは変更されない）
- [ ] [保存] で更新されモーダルが閉じる

### アカウント削除
- [ ] [削除] で確認ダイアログが表示される
- [ ] 確認ダイアログで [OK] をタップすると削除される
- [ ] 削除されたアカウントではログインできなくなる

## 操作フロー

### アカウント作成（正常系）

| # | ユーザー操作 | システム動作 |
|---|------------|------------|
| 1 | [＋ 新規アカウント作成] をタップ | — |
| 2 | — | 作成モーダルを表示 |
| 3 | 各項目を入力 | — |
| 4 | [作成] をタップ | — |
| 5 | — | Account を作成・保存 |
| 6 | — | モーダルを閉じ、一覧を更新 |

### パスワードリセット（正常系）

| # | ユーザー操作 | システム動作 |
|---|------------|------------|
| 1 | アカウントの [編集] をタップ | — |
| 2 | — | 編集モーダルを表示 |
| 3 | [🔑 パスワードをリセット] をタップ | — |
| 4 | — | 新パスワード入力欄＋確認欄を展開表示 |
| 5 | 新パスワードを入力 | — |
| 6 | [保存] をタップ | — |
| 7 | — | Account のパスワードを更新・保存 |

---

## エラーハンドリング

| 条件 | 動作 | メッセージ |
|------|------|-----------|
| 必須項目が未入力で作成 | エラー表示 | 「（項目名）を入力してください」 |
| ユーザーIDが既存と重複 | エラー表示 | 「このユーザーIDは既に使用されています」 |
| パスワードと確認が不一致 | エラー表示 | 「パスワードが一致しません」 |
| 最後の管理者アカウントを削除 | エラー表示、削除を拒否 | 「管理者アカウントが0名になるため削除できません」 |

---

## データモデル

境界コンテキスト「認証・アカウント」で定義済みの `Account` を使用。

```javascript
Account {
  accountId: string,
  userId: string,             // ログイン用ユーザーID（一意）
  password: string,           // ハッシュ化して保存
  name: string,               // 表示名
  role: 'worker' | 'admin',
  language: 'ja' | 'en' | 'si'
}
```
