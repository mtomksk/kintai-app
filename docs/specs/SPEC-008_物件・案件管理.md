# SPEC-008: 物件・案件管理

## 概要
管理者が物件（建物）と案件（個別の清掃作業）を登録・編集・管理する。
物件は継続的な建物情報、案件は物件に紐づく作業日ごとの作業依頼。
リピート物件のフラグ管理、鍵情報の登録、作業指示書（FAX画像）の添付ができる。

## 対応画面
- A-04: 現場管理画面（物件一覧タブ / 案件一覧タブ）

## 対応ユースケース・ルール
- 境界コンテキスト「現場管理」ルール#1, #7, #8, #9, #10, #11, #12, #13, #15, #16, #19

## 受入基準

### 物件一覧タブ
- [ ] 物件が一覧表示される（物件名、住所、リピートフラグ）
- [ ] [🔍 検索] で物件名・住所を検索できる
- [ ] [リピートのみ] / [全件] の絞り込みができる
- [ ] リピート物件＋最新50件程度をデフォルト表示し、ページネーションで切替できる
- [ ] 古い物件は削除せず非表示。検索した場合のみ表示される
- [ ] 各物件に [編集] / [フラグ切替] ボタンがある

### 物件の登録・編集
- [ ] [＋ 新規物件] で物件登録モーダルが開く
- [ ] 入力項目: 物件名（必須）、住所（必須）、部屋番号（任意）、備考（任意）
- [ ] 同じ建物でも部屋番号が異なれば別の物件として登録する
- [ ] [編集] で物件編集モーダルが開く（既存データがプリセット）
- [ ] [保存] で登録・更新される
- [ ] [リピートフラグ切替] でフラグのON/OFFが切替わる

### 案件一覧タブ
- [ ] 案件が一覧表示される（作業予定日、物件名、担当者、鍵情報、指示書有無、評価ランク）
- [ ] [🔍 検索] で物件名・住所・担当者名を検索できる
- [ ] ページネーションで切替できる（1ページ20〜50件）

### 案件の登録
- [ ] [＋ 新規案件] で案件登録フォームが開く
- [ ] 入力項目:
  - 物件選択（既存物件から選択、または新規物件登録）（必須）
  - 作業予定日（必須）
  - 担当作業員（複数選択可）（任意）
  - 鍵情報: 受け取り方法（選択式）＋鍵備考（自由入力）（任意）
  - 作業指示書: FAX画像のアップロード（JPG/PNG/PDF）（任意）
- [ ] 緊急時は必須項目のみ（物件＋日付）で登録できる

### 案件の詳細・評価
- [ ] 案件の [詳細] で詳細表示（鍵情報、指示書画像拡大、評価ランク）
- [ ] 作業報告が提出済みの場合、[評価する] ボタンが表示される
- [ ] [評価する] で評価ランク入力モーダルが開く（ランク選択＋評価備考）

### 担当箇所の管理
- [ ] 担当箇所の選択肢（台所、浴室、リビング等）を管理者が追加・編集できる
- [ ] 追加した選択肢はW-03の作業報告画面に反映される

## 操作フロー

### 物件登録（正常系）

| # | ユーザー操作 | システム動作 |
|---|------------|------------|
| 1 | A-04物件タブで [＋ 新規物件] をタップ | — |
| 2 | — | 物件登録モーダルを表示 |
| 3 | 物件名、住所等を入力 | — |
| 4 | [保存] をタップ | — |
| 5 | — | Property を作成・保存 |
| 6 | — | モーダルを閉じ、物件一覧を更新 |

### 案件登録（正常系）

| # | ユーザー操作 | システム動作 |
|---|------------|------------|
| 1 | A-04案件タブで [＋ 新規案件] をタップ | — |
| 2 | — | 案件登録フォームを表示 |
| 3 | 物件を選択、作業予定日を入力 | — |
| 4 | 担当者・鍵情報・指示書を入力（任意） | — |
| 5 | [保存] をタップ | — |
| 6 | — | Job を作成・保存 |
| 7 | — | フォームを閉じ、案件一覧を更新 |

## エラーハンドリング

| 条件 | 動作 | メッセージ |
|------|------|-----------|
| 物件名が未入力で保存 | エラー表示 | 「物件名を入力してください」 |
| 住所が未入力で保存 | エラー表示 | 「住所を入力してください」 |
| 作業予定日が未入力で案件保存 | エラー表示 | 「作業予定日を入力してください」 |
| FAX画像のアップロード失敗 | エラー表示、再試行可能 | 「画像のアップロードに失敗しました」 |

## データモデル

```javascript
// 物件
Property {
  propertyId: string,         // 物件ID（自動生成）
  name: string,               // 物件名（例: "新宿マンションA"）
  roomNumber: string | null,  // 部屋番号（例: "101"）
  address: string,            // 住所
  isRepeat: boolean,          // リピートフラグ
  isVisible: boolean,         // 表示フラグ（古い物件は非表示）
  note: string | null,        // 備考
  createdAt: datetime
}

// 案件
Job {
  jobId: string,              // 案件ID（自動生成）
  propertyId: string,         // 物件ID（物件に紐づく）
  scheduledDate: string,      // 作業予定日
  assignedWorkers: string[],  // 担当作業員IDの配列
  keyInfo: KeyInfo | null,    // 鍵情報
  instructionImage: string | null, // 指示書画像URL
  status: JobStatus,          // 案件ステータス
  evaluationRank: string | null,   // 評価ランク
  evaluationNote: string | null,   // 評価備考
  createdAt: datetime
}

// 担当箇所マスタ（管理者が拡張可能）
CleaningAreaMaster {
  areaId: string,
  name: string,               // 例: "台所", "浴室"
  displayOrder: number,       // 表示順
  isActive: boolean           // 有効/無効
}
```
