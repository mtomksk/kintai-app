# SPEC-014: 勤務履歴・給与明細

## 概要
作業員が自分の過去の勤務履歴を確認する。
管理者がアップロードした給与明細PDF（現在LINEで送付しているもの）を閲覧できる。

## 対応画面
- W-04: 勤務履歴画面

## 対応ユースケース・ルール
- 境界コンテキスト「勤怠管理」ルール#15
- 境界コンテキスト「人事・評価」ルール#8, #9

---

## 受入基準

### 勤務履歴の表示
- [ ] 月単位で勤務履歴が一覧表示される
- [ ] [◀] / [▶] で月を切替できる
- [ ] 各日付にステータスが表示される（✅ 勤務済み / ─ 休み）
- [ ] 出退勤時刻・勤務時間は表示しない（ルール#15: 給与計算とのズレ防止）
- [ ] 月の勤務日数の合計のみ表示する（時間の合計は非表示）

### 給与明細PDF閲覧
- [ ] 管理者がアップロードした給与明細PDFを閲覧できる
- [ ] 自分宛のPDFのみ表示される（他の作業員の明細は見られない）
- [ ] PDFがない月は「明細はまだ登録されていません」と表示する

### 給与明細PDF登録（管理者側）
- [ ] 管理者が作業員ごとに給与明細PDFを登録できる
- [ ] 登録場所はA-03（作業員詳細）またはA-07（設定画面）で検討

---

## 操作フロー

### 勤務履歴の確認（正常系）

| # | ユーザー操作 | システム動作 |
|---|------------|------------|
| 1 | W-01で [履歴] をタップ | — |
| 2 | — | W-04を表示。当月の勤務履歴を読み込み |
| 3 | 日付ごとのステータスを確認 | — |
| 4 | [◀] で前月に切替 | — |
| 5 | — | 前月の勤務履歴を読み込み・表示 |

---

## エラーハンドリング

| 条件 | 動作 | メッセージ |
|------|------|-----------|
| データ読み込み失敗 | エラー表示 | 「データの読み込みに失敗しました」 |
| 勤務記録がない月 | 空の一覧を表示 | 「この月の勤務記録はありません」 |

## データモデル

```javascript
// 給与明細
PaySlip {
  paySlipId: string,
  workerId: string,           // 対象作業員ID
  yearMonth: string,          // 対象年月（例: "2026-07"）
  pdfUrl: string,             // PDFファイルURL
  uploadedAt: datetime,       // アップロード日時
  uploadedBy: string          // アップロードした管理者ID
}
```
