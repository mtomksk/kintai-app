# SPEC-006: 作業報告

## 概要
作業員が現場作業の完了後に作業報告を送信し、管理者がその報告を一覧で確認・編集する。
作業報告は「未読/既読」で管理され、管理者は担当箇所の修正や管理者メモの追記ができる。
差し戻し機能はアプリに実装しない（2026-07-15 MTG決定）。

## 対応画面
- W-03: 作業報告画面（作業員が報告を送信）
- A-08: 作業報告一覧画面（管理者が報告を一覧確認）
- A-09: 作業報告詳細画面（管理者が報告を閲覧・編集）
- A-01: 管理ダッシュボード（未読バナー表示）

## 対応ユースケース・ルール
- 境界コンテキスト「現場管理」ルール#3, #4, #5, #6, #19, #20, #22
- 境界コンテキスト「多言語対応」ルール#5, #6

## 受入基準

### W-03: 作業報告の送信（作業員側）
- [ ] 現場終了後の促しまたは未提出バッジから W-03 に遷移できる
- [ ] 案件名が自動で設定される（作業中だった案件）
- [ ] 担当箇所を複数選択できる（台所, 浴室, リビング, トイレ, 玄関, その他）
- [ ] 証拠写真を添付できる（任意。カメラまたはフォトライブラリから選択）
- [ ] 写真ごとにコメントを入力できる
- [ ] 備考欄に自由入力ができる（シンハラ語等の母国語で入力可能）
- [ ] [報告を送信] で報告が保存され、W-01に戻る（完了メッセージ表示）
- [ ] 送信時に備考欄のテキストが翻訳APIで自動翻訳される
- [ ] 翻訳失敗時は原文のみで保存される（エラーにしない）
- [ ] [← 戻る] で入力内容の保持 or 破棄を確認ダイアログで選択できる

### A-08: 作業報告一覧（管理者側）
- [ ] A-01の未読バナーから遷移した場合、全作業員の報告が未読タブで表示される
- [ ] A-03の [作業報告を見る] から遷移した場合、該当作業員でフィルタされる
- [ ] タブ [未読(n)] / [既読] / [すべて] で表示を切替できる
- [ ] デフォルトは未読タブが選択された状態
- [ ] 未読タブのラベルに未読件数が表示される（例: `未読(3)`）
- [ ] 各報告カードに作業員名、案件名、担当箇所（要約）、写真有無、報告日時が表示される
- [ ] 未読の報告カードには 🔵 マークが表示される
- [ ] 報告は新しい順（降順）で並ぶ
- [ ] 報告カードをタップすると A-09（詳細画面）に遷移する
- [ ] A-09への遷移時に、その報告が自動で「既読」に更新される
- [ ] [← 戻る] で遷移元の画面（A-01 or A-03）に戻れる

### A-09: 作業報告詳細（管理者側 — 閲覧モード）
- [ ] 基本情報（作業員名、案件名、報告日時）が表示される
- [ ] 担当箇所の選択内容が表示される
- [ ] 証拠写真がサムネイルで表示される
- [ ] 写真サムネイルをタップすると拡大表示（モーダル）される
- [ ] 写真ごとのコメントが表示される
- [ ] 備考の原文（シンハラ語等）と翻訳文（日本語）が並べて表示される
- [ ] 管理者メモ欄が表示される（未記入時はプレースホルダ表示）
- [ ] [✏️ 編集] ボタンで編集モードに切替できる
- [ ] [← 戻る] で A-08 に戻れる

### A-09: 作業報告詳細（管理者側 — 編集モード）
- [ ] 以下の項目が編集可能になる:
  - 担当箇所（チェックの追加・削除）
  - 備考の翻訳文（翻訳ミスの修正）
  - 管理者メモ（自由入力）
- [ ] 以下の項目は変更不可（グレー背景で明示）:
  - 基本情報（作業員名、案件名、報告日時）
  - 証拠写真＋コメント
  - 備考の原文
- [ ] [保存] で変更が保存され、閲覧モードに戻る
- [ ] [キャンセル] で変更を破棄して閲覧モードに戻る
- [ ] 編集中に [← 戻る] を押した場合、「変更を破棄しますか？」確認ダイアログが表示される
- [ ] 管理者の編集履歴は保持しない（最新状態のみ保存）

### A-01: 未読バナー
- [ ] 未読の作業報告が1件以上ある場合、管理タブに通知バナーが表示される
- [ ] バナーに未読件数が表示される（例: `📋 未読の作業報告: 3件`）
- [ ] バナーをタップすると A-08（未読タブ）に遷移する
- [ ] 未読が0件の場合はバナーが非表示になる
- [ ] バナーは [自分の打刻] タブには表示しない

## 操作フロー

### 作業報告の送信（W-03 正常系）

| # | ユーザー操作 | システム動作 |
|---|------------|------------|
| 1 | 現場終了後の促し → [報告する] をタップ | — |
| 2 | — | W-03を表示。案件名を自動設定 |
| 3 | 担当箇所をチェック | — |
| 4 | 証拠写真を添付（任意） | — |
| 5 | 写真コメントを入力（任意） | — |
| 6 | 備考を入力（任意） | — |
| 7 | [報告を送信] をタップ | — |
| 8 | — | WorkReport を作成・保存 |
| 9 | — | 備考テキストを翻訳APIに送信 |
| 10 | — | 原文＋翻訳文を WorkReport に保存 |
| 11 | — | readStatus を 'unread' に設定 |
| 12 | — | W-01に戻り、完了メッセージを表示 |

### 作業報告の確認（A-08 → A-09 正常系）

| # | ユーザー操作 | システム動作 |
|---|------------|------------|
| 1 | A-01の未読バナーをタップ | — |
| 2 | — | A-08を表示（未読タブ、全作業員） |
| 3 | 報告カードをタップ | — |
| 4 | — | 該当報告の readStatus を 'read' に更新 |
| 5 | — | A-09（閲覧モード）を表示 |
| 6 | 内容を確認 | — |
| 7 | [← 戻る] をタップ | — |
| 8 | — | A-08に戻る。未読タブの件数が更新される |

### 作業報告の編集（A-09 編集モード 正常系）

| # | ユーザー操作 | システム動作 |
|---|------------|------------|
| 1 | A-09閲覧モードで [✏️ 編集] をタップ | — |
| 2 | — | 編集モードに切替。編集可能項目が入力可能になる |
| 3 | 担当箇所を修正 / 翻訳文を修正 / 管理者メモを記入 | — |
| 4 | [保存] をタップ | — |
| 5 | — | WorkReport を更新・保存 |
| 6 | — | 閲覧モードに戻る |

## エラーハンドリング

| 条件 | 動作 | メッセージ |
|------|------|-----------|
| W-03: 担当箇所を1つも選択せずに送信 | 送信ボタン非活性 or エラー表示 | 「担当箇所を1つ以上選択してください」 |
| W-03: 写真のアップロード失敗 | エラー表示、再試行可能 | 「写真のアップロードに失敗しました」 |
| W-03: 翻訳API失敗 | 原文のみで保存（エラーにしない） | — |
| W-03: ネットワークエラーで送信失敗 | エラー表示、入力内容は保持 | 「送信に失敗しました。再度お試しください」 |
| A-09: 編集中に戻るボタン | 確認ダイアログ表示 | 「変更を破棄しますか？」[破棄する] / [編集に戻る] |
| A-09: 保存失敗 | エラー表示、入力内容は保持 | 「保存に失敗しました。再度お試しください」 |

## データモデル

```javascript
// 作業報告
WorkReport {
  reportId: string,           // 報告ID（自動生成）
  jobId: string,              // 案件ID（W-03表示時に自動設定）
  workerId: string,           // 送信した作業員のID
  workerName: string,         // 作業員名（表示用）
  propertyName: string,       // 物件名（例: "新宿マンションA 101"）
  submittedAt: datetime,      // 報告日時（送信タイムスタンプ）

  // 報告内容
  cleaningAreas: string[],    // 担当箇所（例: ["台所", "浴室"]）
  photos: ReportPhoto[],      // 証拠写真（0枚以上）
  note: TranslatedText | null,// 備考（原文＋翻訳文）

  // 管理者関連
  readStatus: 'unread' | 'read', // 未読/既読ステータス
  adminMemo: string | null,   // 管理者メモ（管理者が記入）
  readAt: datetime | null     // 既読になった日時
}

// 証拠写真
ReportPhoto {
  photoId: string,            // 写真ID
  imageUrl: string,           // 画像ファイルURL
  comment: string | null      // 写真コメント（例: "壁損傷"）
}

// 翻訳付きテキスト（境界コンテキスト「多言語対応」で定義済み）
TranslatedText {
  original: string,           // 原文（シンハラ語等）
  originalLang: string,       // 原文の言語コード（例: "si"）
  translated: string | null,  // 翻訳文（日本語）
  translatedLang: string      // 翻訳先言語コード（例: "ja"）
}
```

## UI仕様

### W-03: 作業報告画面
- **ヘッダー**: [← 戻る] + 「作業報告」タイトル
- **案件名**: 自動設定。読み取り専用で表示
- **担当箇所**: チェックボックス一覧（台所, 浴室, リビング, トイレ, 玄関, その他）
  - 担当箇所の選択肢は管理者が拡張可能（ルール#19。拡張UIはSPEC-008で定義）
- **証拠写真**: [＋ 写真追加] ボタン → カメラ or フォトライブラリ起動
  - 各写真の下にコメント入力欄
- **備考**: 自由入力テキストエリア
- **フッター**: [📤 報告を送信] ボタン

### A-08: 作業報告一覧画面
- **ヘッダー**: [← 戻る] + 「作業報告一覧」タイトル
- **作業員フィルタ表示**: A-03から遷移時のみ「👤 ○○ の報告」を表示
- **タブ**: [未読(n)] / [既読] / [すべて]
- **報告カード**: 作業員名（🔵マーク付き）、案件名、担当箇所（要約）、📷アイコン（写真あり時）、報告日時
- **ソート**: 新しい報告が上（降順）
- **件数表示**: 画面下部に「全n件」を表示

### A-09: 作業報告詳細画面
- **ヘッダー（閲覧モード）**: [← 戻る] + 「作業報告詳細」タイトル + [✏️ 編集]
- **ヘッダー（編集モード）**: [← 戻る] + 「作業報告詳細」タイトル + [キャンセル] [保存]
- **基本情報セクション**: 作業員名、案件名、報告日時
- **担当箇所セクション**: 閲覧時はチェック状態表示、編集時はチェック変更可能
- **証拠写真セクション**: サムネイル一覧（タップで拡大）＋コメント表示
- **備考セクション**: 原文（🇱🇰アイコン付き）＋翻訳文（🇯🇵アイコン付き）。編集時は翻訳文のみ編集可能
- **管理者メモセクション**: 閲覧時はテキスト表示、編集時はテキストエリア
- **フッター（編集モード）**: [キャンセル] [保存]（画面下部にも配置）
