# SPEC-015: 設定画面

## 概要
作業員向け設定画面（W-05）で言語切替を行う。
管理者向け設定画面（A-07）で自分のパスワード変更、GPS設定、翻訳設定、データ管理を行う。

## 対応画面
- W-05: 設定画面（作業員）
- A-07: 設定画面（管理者）

## 対応ユースケース・ルール
- 境界コンテキスト「認証・アカウント」ルール#9
- 境界コンテキスト「多言語対応」ルール#1, #2

---

## 受入基準

### W-05: 作業員向け設定画面
- [ ] プロフィール（名前、ID）が読み取り専用で表示される
- [ ] 言語設定をラジオボタンで切替できる（日本語 / English / シンハラ語）
- [ ] 言語を変更すると画面全体が選択言語で即座に再描画される
- [ ] パスワード変更機能はない（管理者がA-06で一括管理）
- [ ] [ログアウト] ボタンで確認ダイアログ → ログアウト → S-01に遷移

### A-07: 管理者向け設定画面
- [ ] 自分のアカウント情報（名前、ID）が表示される
- [ ] [パスワードを変更] でパスワード変更モーダルが開く
- [ ] パスワード変更モーダル: 現在のパスワード、新パスワード、確認入力
- [ ] GPS設定: 打刻時GPS取得の ON/OFF トグル
- [ ] 翻訳設定: 自動翻訳の ON/OFF トグル、翻訳先言語の選択
- [ ] データ管理: [データエクスポート]（将来機能）/ [データバックアップ]（将来機能）
- [ ] [ログアウト] ボタンで確認ダイアログ → ログアウト → S-01に遷移

## 操作フロー

### 管理者パスワード変更（正常系）

| # | ユーザー操作 | システム動作 |
|---|------------|------------|
| 1 | A-07で [パスワードを変更] をタップ | — |
| 2 | — | パスワード変更モーダルを表示 |
| 3 | 現在のパスワード、新パスワード、確認を入力 | — |
| 4 | [変更] をタップ | — |
| 5 | — | 現在のパスワードを検証 |
| 6 | — | パスワードを更新・保存 |
| 7 | — | 完了メッセージを表示、モーダルを閉じる |

---

## エラーハンドリング

| 条件 | 動作 | メッセージ |
|------|------|-----------|
| 現在のパスワードが不正 | エラー表示 | 「現在のパスワードが正しくありません」 |
| 新パスワードと確認が不一致 | エラー表示 | 「パスワードが一致しません」 |
| 新パスワードが未入力 | エラー表示 | 「新しいパスワードを入力してください」 |

---

## データモデル

新規モデルなし。既存の `Account` モデルを使用。

```javascript
// システム設定（管理者が管理）
SystemSettings {
  gpsEnabled: boolean,        // 打刻時GPS取得 ON/OFF
  autoTranslateEnabled: boolean, // 自動翻訳 ON/OFF
  translateTargetLang: string    // 翻訳先言語（デフォルト: "ja"）
}
```
