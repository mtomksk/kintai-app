# SPEC-013: 多言語対応

## 概要
アプリのUIを日本語・英語・シンハラ語の3言語で表示する。
UIラベルは翻訳ファイル（i18n）で管理し、自由入力テキストは翻訳API（Google Cloud Translation）で自動翻訳する。

## 対応画面
- 全画面

## 対応ユースケース・ルール
- 境界コンテキスト「多言語対応」ルール#1〜#7

---

## 受入基準

### UI翻訳（i18nファイル）
- [ ] 全てのUIラベル・ボタン・メッセージが3言語で表示される
- [ ] 対応言語: 日本語（ja）、英語（en）、シンハラ語（si）
- [ ] 翻訳ファイルはJSON形式で管理する
- [ ] 言語切替時に画面全体が選択言語で再描画される
- [ ] 未翻訳のキーがある場合は日本語をフォールバックとして表示する

### 自動翻訳（翻訳API）
- [ ] 備考欄等の自由入力テキストは送信時にGoogle Cloud Translation APIで翻訳される
- [ ] 原文と翻訳文の両方が保存される
- [ ] 翻訳先言語は管理者のデフォルト言語（日本語）
- [ ] 翻訳APIが利用できない場合、原文のみで保存する（エラーにしない）

### 言語設定
- [ ] アカウントごとに表示言語が設定される
- [ ] 作業員のデフォルト言語はシンハラ語（si）
- [ ] 管理者のデフォルト言語は日本語（ja）
- [ ] W-05（作業員設定画面）で言語を変更できる
- [ ] 初回ログイン時はブラウザの言語を自動検出する

### 作業指示書（FAX）
- [ ] 作業指示書（FAX画像）は日本語のまま表示する（翻訳不要。作業員は教育済み）

## 操作フロー

### 自由入力テキストの翻訳（正常系）

| # | ユーザー操作 | システム動作 |
|---|------------|------------|
| 1 | W-03で備考欄にシンハラ語で入力 | — |
| 2 | [報告を送信] をタップ | — |
| 3 | — | 備考テキストをGoogle Cloud Translation APIに送信 |
| 4 | — | 翻訳結果を取得（シンハラ語→日本語） |
| 5 | — | TranslatedText { original, translated } として保存 |

### 翻訳API失敗時

| # | ユーザー操作 | システム動作 |
|---|------------|------------|
| 1 | [報告を送信] をタップ | — |
| 2 | — | 翻訳APIにリクエスト → 失敗 |
| 3 | — | TranslatedText { original, translated: null } として保存 |
| 4 | — | 送信処理は正常に続行（エラーにしない） |

---

## データモデル

SPEC-006 で定義した `TranslatedText` を使用。

```javascript
// 翻訳ファイルの構造
i18n/{lang}.json
{
  "login": {
    "title": "勤怠管理アプリ",
    "userId": "ユーザーID",
    "password": "パスワード",
    "submit": "ログイン"
  },
  // ...画面ごとにネスト
}
```
